① API 키 설정 (최초 1회)
사고위험 데이터 연도는 현재연도부터 역순으로 조회해 실제로 제공되는 최신연도를 자동 선택합니다.
카카오 키와 공공데이터포털 키는 현재 기능에 사용됩니다. ITS 인증키는 발급 후 현재 사고·공사·통제 상세 기능에 연결할 예정입니다. 최초 1회 입력하면 이 PC 브라우저(localStorage)에 계속 저장됩니다. 배포용 서비스에서는 API 키를 브라우저에 노출하지 말고 서버에서 호출해야 합니다.
출장지·경유지는 상림리 64-1처럼 짧게 입력해도 됩니다. 카카오 주소/키워드검색을 함께 사용하고 경상남도 결과를 우선 반영합니다. 출발지는 경상남도 진주시 칠암동 414-4로 고정했습니다.
