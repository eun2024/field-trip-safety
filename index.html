도착지 주소만 입력해 경로·기상·사고위험·실시간 교통상황을 한 화면에서 확인
v3.1 직원배포용
직원용 · API 설정 없이 바로 사용할 수 있습니다. 도착지와 필요 시 경유지·출발 예정일시만 입력해 주세요.
위에서 아래 순서대로 경유합니다.
출발시간만 입력하면 경로 소요시간을 이용해 경유지·도착지의 예상 통과시각을 자동 계산합니다.
도착지는 시·군 + 읍·면·동 + 상세주소까지 입력해 주세요. 경유지는 선택사항이며, 입력하지 않으면 자동으로 건너뜁니다. 경유지는 ＋ 경유지 추가로 최대 5개까지 추가하고, 각 줄의 − 버튼으로 삭제할 수 있습니다. 예: 산청군 산청읍 옥산리 465-3. 경상남도는 자동으로 붙입니다. 검색결과는 입력한 시·군·읍면·리·지번과 일치하는지 다시 검증하며, 일치하지 않으면 점검을 진행하지 않습니다. 출발지는 경상남도 진주시 칠암동 414-4로 고정했습니다.
